# Working notes

Internal notes from the programme that produced the results, kept for the
record. They predate the ICASSP 2027 manuscript and refer to an earlier,
longer draft; where they disagree with the paper, the paper is current.

| File | What it is |
|---|---|
| `FINDINGS.md` | running narrative of every finding, null and failed design, written as the runs came in |
| `EXPECTED_RESULTS.md` | pre-run expectations and decision rules for six follow-up runs requested by reviewers of the earlier draft |
| `EXPERIMENTS.md` | the original experimental programme, tiered, with its status at the time |
